AHJ Report

Generate a report that contains the Authority Having Jurisdiction information as well as Project and Client Information for a given project.

Process Overview:

  • Fetch project and client details from Core
  • Search AHJ registry for current IBC Code
  • Identify relevant ammendments via PDF and web link search using Bing
  • Generate formatted Excel workbook with all data

Output: Excel workbook saved in the AHJ_Report directory in the project_info directory for the project.

🚀

Generate All Web Scraping Reports

After generating an AHJ Report for a project you can automate generating the ASCE Hazard Report, ASCE Hazard Summary, USDA Soil Linear Extensibility, and the Unified Soil Classification Report all at once or opt to generate the reports individually if you only need a specific one.

Reports Generated:

  • ASCE Hazard Full Report PDF - Wind, Ice, Snow, Seismic.
  • USDA Soil Linear Extensibility PDF
  • USDA Soil Unified Soil Classification PDF
  • ASCE Hazard Summary Table - Integrated into existing AHJ Report

Prerequisite: AHJ Report must exist for the project beforehand.

🔬

ASCE Hazard Tool Reports

Generate the ASCE Hazard Report PDF or the ASCE Hazard Report Summary Table for a given project.

Available Reports:

  • ASCE Summary Table - Hazard data extracted and added to existing AHJ report
  • ASCE Full Report PDF - Wind, Snow, Ice, Seismic PDF downloaded to project directory

Integration: The report PDF will be saved to ASCE_Hazard_Report in the project_info directory

🌍

USDA Soil Survey Reports

Generate the Linear Extensibility Report PDF and the Unified Soil Classification Report PDF for a project simultaneously.

Generated Reports:

  • USDA Soil Linear Extensibility Report
  • USDA Soil Unified Soil Classification Report

Processing Time: Process takes 2 - 4 minutes
