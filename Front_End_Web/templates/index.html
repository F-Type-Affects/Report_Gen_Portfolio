SML Project Reporting Application

First Time Users MUST "Login & Authenticate" before doing anything else.

This will add your user credentials to the database and allow you to use the application.

To Create AHJ Report
    1. Select Fetch Project Details to query and return the relevant Project & Client information
      • Select your email from the drop down
      • Enter the project number taking care to include padding zeros
      • If the information is correct select confirm details
    2. Select Find AHJ & Amendments to find the AHJ for the project address and possible Amendments
      • Select Search AHJ to find the AHJ information for the address
      • Then select Search Amendments to query possible Amendments to the IBC Codes
      • Finally select Confirm and Store to store the data for export
    3. Finally select Export AHJ Report to export all of the information to an excel workbook
      • The workbook will be saved in the project directory on the companies J Drive
To Generate a Calculation Cover Sheet
    1. Select Generate Cover Letter
    2. Select your email from the drop down
      • This is how your name is added to the report
    3. Search the project number
    4. Confirm the details are correct and select Confirm
