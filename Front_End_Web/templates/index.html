Welcome to the "SML Report Generator"

If this is your first time using the application, you must first select "Login & Authenticate". This will take you through BQE Core's Authentication process and add your credentials to the database.

  • Select "Create Project" if you wish to create a new project and add it to Core.
  • Select "Update Project Address" to either:
    • Add an address to an existing project from the memo.
    • Manually enter the address and update an existing project in Core.
  • Select "Fetch Project Details" to retrieve relevant project and client information.
    • You must do this prior to exporting the Project Details to an Excel workbook or to search the AHJ and Amendments for a given project number.
  • Select "Find AHJ & Amendments" to:
    • View AHJ Information and possible amendments to building codes for a given address.
    • Create a new project report (Excel workbook).
    • Update a project report workbook missing this information.
  • Select "Export Project Details" to export any of the information queried to a project report.
  • Select "Create Cover Sheet" to build a report cover sheet from a project report.
